## Category

Productivity

## Detailed description

Save the ChatGPT conversation currently open in your browser as a clean Markdown file.

Thread to Markdown for ChatGPT is a focused, privacy-first exporter for people who archive research, project discussions, documentation, decisions, and long AI-assisted work sessions.

MAIN FEATURES

• Exports user and assistant messages from the open conversation.  
• Adds the conversation title, export time, and source URL.  
• Saves a readable .md file to the standard Downloads folder.  
• Uses a safe filename based on the conversation title and date.  
• Works only after you explicitly press Export.  
• Supports English and Ukrainian interface text.

PRIVACY

The conversation is processed locally in Chrome. The extension does not send conversation content, browsing activity, account information, or generated files to the developer or any third party. There is no telemetry, analytics, advertising, tracking, remote code, or custom server.

PERMISSIONS

• activeTab: access only to the tab you explicitly selected.  
• scripting: read the open conversation after you press Export.  
• downloads: save the Markdown file to your device.

No broad host permission is requested.

HOW TO USE

1. Open a conversation on chatgpt.com.  
2. Select the extension icon.  
3. Press “Export open thread”.  
4. Find the Markdown file in Downloads.

## Single purpose statement

The extension's single purpose is to export the ChatGPT conversation explicitly selected by the user to a local Markdown file.

## Permission justifications

### activeTab
Required to access only the active ChatGPT tab after the user opens the extension and presses Export.

### scripting
Required to read the visible conversation content and convert it to Markdown after the user's explicit action.

### downloads
Required to save the generated Markdown file to the user's local Downloads folder.

## Remote code

No. All executable code is included in the extension package.

## Data usage declarations

The extension locally processes website content, personal communications, and user-generated content only to create the requested Markdown file. It does not collect, transmit, retain, sell, or share this data.
