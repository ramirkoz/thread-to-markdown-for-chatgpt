## Title

## Summary (132 characters maximum)

## Category

Productivity

## Detailed description

Save selected messages from the ChatGPT conversation currently open in your browser as clean local files or copy them to the clipboard.

Thread to Markdown for ChatGPT is a focused, privacy-first exporter for people who archive research, project discussions, documentation, decisions, and long AI-assisted work sessions.

MAIN FEATURES

• Loads user and assistant messages from the open conversation.  
• Lets you select individual messages, select all, or clear the selection.  
• Exports selected messages as Markdown, plain text, or JSON.  
• Copies selected messages to the clipboard locally.  
• Preserves headings, lists, tables, links, quotes, emphasis, inline code, and fenced code blocks in structured exports.  
• Adds the conversation title, export time, source URL, and a safe filename.  
• Removes interface-only controls and unusable temporary links from the export.  
• Works only after you explicitly request loading, copying, or exporting.  
• Supports English and Ukrainian interface text.

PRIVACY

The conversation is processed locally in Chrome. The extension does not send conversation content, browsing activity, account information, clipboard content, or generated files to the developer or any third party. There is no telemetry, analytics, advertising, tracking, remote code, or custom server.

PERMISSIONS

• activeTab: access only to the tab you explicitly selected.  
• scripting: read the open conversation after you request it.  
• downloads: save the selected export to your device.

No broad host permission is requested.

HOW TO USE

1. Open a conversation on chatgpt.com.  
2. Select the extension icon.  
3. Load the open conversation.  
4. Choose the messages and output format.  
5. Export the selection or copy it to the clipboard.

## Single purpose statement

The extension's single purpose is to let the user select messages from the open ChatGPT conversation and save or copy that selected content locally.

## Permission justifications

### activeTab
Required to access only the active ChatGPT tab after the user opens the extension and requests message loading or export.

### scripting
Required to read the visible conversation and convert the selected messages after the user's explicit action.

### downloads
Required to save the generated Markdown, TXT, or JSON file to the user's local Downloads folder.

## Remote code

No. All executable code is included in the extension package.

## Data usage declarations

The extension locally processes website content, personal communications, and user-generated content only to create the requested local export or clipboard copy. It does not collect, transmit, retain, sell, or share this data.
