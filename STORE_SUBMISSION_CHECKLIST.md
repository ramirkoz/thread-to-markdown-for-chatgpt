# Chrome Web Store submission checklist

## Package

- Upload `thread-to-markdown-for-chatgpt-1.4.0-chrome-web-store.zip`.
- Confirm `manifest.json` is at the ZIP root.
- Confirm version `1.4.0` and Manifest V3.

## Store listing

- Language: English (add Ukrainian localized listing after the English listing is saved).
- Category: Productivity.
- Copy the title, summary, and detailed description from `STORE_LISTING.md`.
- Upload the 128×128 icon from `extension/icons/icon128.png`.
- Upload at least one 1280×800 screenshot.
- Upload the 440×280 small promotional tile.
- Optional: upload the 1400×560 marquee image.
- Add the GitHub repository as the website and support URL.

## Privacy practices

- Single purpose: export the user-selected ChatGPT conversation to a local Markdown file.
- Website content: handled locally for the requested export.
- Personal communications: handled locally because the selected conversation may contain them.
- User-generated content: handled locally because the selected conversation may contain it.
- Data sold: No.
- Data transferred: No.
- Data used for advertising: No.
- Data used for analytics: No.
- Remote code: No.
- Privacy policy: link to the public `PRIVACY.md` page.

## Distribution

- Visibility: Public.
- Regions: all available regions unless a legal restriction is identified.
- Pricing: Free.

## Final review

- Install the uploaded package from the dashboard test link.
- Export a short and a long conversation.
- Verify the file downloads and opens as UTF-8 Markdown.
- Verify the listing disclaimer and privacy policy links.
- Submit for review.
