# Privacy Policy — Thread to Markdown for ChatGPT

**Effective date:** 2 August 2026  
**Extension version:** 1.4.0

## Summary

Thread to Markdown for ChatGPT exports the conversation currently open in the user's browser to a Markdown file. The extension processes the page locally on the user's device and does not send conversation content, browsing history, account information, or generated files to the developer or to any third party.

## Data handled by the extension

After the user presses **Export open thread**, the extension temporarily reads the visible content and URL of the active ChatGPT conversation so it can build the requested Markdown file. This content may include personal communications and user-generated content because it comes from the conversation selected by the user.

The extension:

- does not collect data on a remote server;
- does not transmit conversation content or URLs to the developer;
- does not use analytics, telemetry, advertising, tracking pixels, cookies, or fingerprinting;
- does not sell or share user data;
- does not retain a copy of exported content after creating the local download;
- does not run on unrelated websites.

The generated Markdown file is saved through Chrome's Downloads feature. The user controls that file and can delete it at any time.

## Permission use

- **activeTab:** access only to the tab where the user explicitly opens the extension.
- **scripting:** read the open conversation after the user presses the export button.
- **downloads:** save the generated Markdown file to the user's device.

No broader host permission is requested.

## Limited Use

Use of information received from browser permissions is limited to the extension's single purpose: exporting the user-selected conversation to a local Markdown file. The information is not transferred, used for advertising, used for profiling, or made available for human review by the developer.

## Security

All processing happens inside the browser. The extension contains no remotely hosted code and makes no network requests.

## Changes

If the extension's data practices change, this policy and the Chrome Web Store privacy disclosures will be updated before the changed version is published.
