# ChatExtra Toolkit 2.0.0 — детальний посібник користувача

## 1. Що це

ChatExtra Toolkit — неофіційне Chrome-розширення для роботи з ChatGPT і вебсторінками. Основна функція залишається незмінною: вибрати повідомлення відкритої розмови ChatGPT і локально експортувати їх у потрібному форматі.

Додатково розширення вміє:

- шукати повідомлення у відкритій гілці;
- переходити до конкретного повідомлення;
- копіювати вибрані повідомлення;
- експортувати Markdown, HTML, PDF, ZIP, TXT та JSON;
- зберігати локальну бібліотеку промптів;
- зберігати локальні знімки чатів із папками, тегами й нотатками;
- масово експортувати збережені чати;
- робити резервну копію та відновлення локальної бібліотеки;
- передавати у новий ChatGPT-чат виділений текст, очищений текст сторінки, видимий скриншот або доступний транскрипт YouTube.

Уся підготовка даних виконується локально у браузері. Розширення не має власного сервера й не використовує телеметрію.

---

## 2. Встановлення development/release ZIP

1. Завантажте ZIP ChatExtra Toolkit.
2. Розпакуйте ZIP у постійну папку на комп'ютері.
3. Відкрийте Chrome і перейдіть на `chrome://extensions`.
4. Увімкніть **Режим розробника**.
5. Натисніть **Завантажити розпаковане розширення / Load unpacked**.
6. Виберіть папку `extension`.
7. Закріпіть зелену іконку ChatExtra Toolkit на панелі Chrome.

Після оновлення локальної збірки:

1. замініть файли у папці розширення новою версією;
2. відкрийте `chrome://extensions`;
3. натисніть **Оновити / Reload** на картці ChatExtra Toolkit.

Перезавантажувати саму вкладку ChatGPT через маршрутизацію меню у 2.0.0 зазвичай більше не потрібно: меню визначається при кожному кліку по іконці.

---

## 3. Як працює іконка розширення

ChatExtra Toolkit має два режими одного й того самого ярлика.

### На ChatGPT

Лівий клік по іконці відкриває основне меню роботи з розмовою:

1. пошук і навігація;
2. вибір повідомлень;
3. формат експорту;
4. кнопки **Копіювати вибране** та **Експортувати вибране**;
5. нижче — бібліотека промптів;
6. ще нижче — локальна бібліотека чатів.

Основний експорт навмисно розташований вище за додаткові функції.

### На інших сайтах

Лівий клік по тій самій іконці відкриває меню **Інструменти сайту**:

- Виділений текст;
- Поточна сторінка;
- Видимий скриншот;
- Субтитри YouTube, якщо відкрите YouTube-відео й транскрипт доступний.

Жодна з цих дій не натискає кнопку Send у ChatGPT автоматично.

## 4. Експорт відкритої розмови ChatGPT

1. Відкрийте потрібну розмову ChatGPT.
2. Натисніть іконку ChatExtra Toolkit.
3. Дочекайтеся завантаження списку повідомлень.
4. За потреби скористайтеся пошуком.
5. Увімкніть фільтр:
   - Усі;
   - Користувач;
   - ChatGPT.
6. Зніміть прапорці з повідомлень, які не потрібно експортувати.
7. Виберіть формат.
8. Натисніть **Копіювати вибране** або **Експортувати вибране**.

### Формати

**Markdown (.md)**  
Найзручніший для архіву, GitHub, Obsidian, Notion та подальшого редагування.

**HTML (.html)**  
Самодостатня локальна HTML-сторінка зі стилями.

**PDF**  
Відкривається підготовлена сторінка друку. У Chrome виберіть «Зберегти як PDF» і вимкніть колонтитули.

**Portable ZIP (.zip)**  
Містить Markdown, HTML, TXT, JSON, manifest, README та доступні локально зображення/вкладення.

**TXT (.txt)**  
Звичайний текст без складного форматування.

**JSON (.json)**  
Структуровані дані для автоматичної обробки.

## 5. Пошук і навігація по довгому чату

1. Введіть слово або фрагмент у поле пошуку.
2. Список нижче покаже лише відповідні повідомлення.
3. Стрілки `←` і `→` перемикають знайдені результати.
4. `Enter` переходить до наступного результату.
5. `Shift + Enter` переходить до попереднього.
6. Кнопка `↗` біля повідомлення прокручує саму сторінку ChatGPT до відповідного повідомлення.
7. Поточне повідомлення коротко підсвічується зеленою рамкою.

Пошук не змінює прапорці вибраних для експорту повідомлень.

---

## 6. Локальна бібліотека промптів

Блок **Локальна бібліотека промптів** розташований після основних кнопок експорту.

Можна:

- додати промпт;
- задати назву;
- редагувати текст;
- шукати промпти;
- копіювати готовий промпт;
- видаляти непотрібні.

Промпти зберігаються лише у профілі браузера.

---

## 7. Локальна бібліотека чатів

Блок **Local workspace / Локальна бібліотека чатів** також розташований після основного експорту.

### Зберегти поточний чат

1. Відкрийте потрібну розмову ChatGPT.
2. Відкрийте ChatExtra Toolkit.
3. Розгорніть локальну бібліотеку чатів.
4. За бажанням вкажіть:
   - папку;
   - теги через кому;
   - локальну нотатку.
5. Натисніть **Зберегти чат**.

Зберігається Markdown-знімок розмови, її URL, назва, папка, теги, нотатка, кількість повідомлень та службові дати.

### Знайти збережений чат

Використовуйте:

- текстовий пошук;
- фільтр за папкою.

Пошук перевіряє назву, теги та нотатку.

### Відкрити збережений чат

Натисніть кнопку відкриття біля потрібного запису. Відкриється оригінальний URL ChatGPT.

---

## 8. Масовий ZIP-експорт збережених чатів

1. Відкрийте локальну бібліотеку чатів.
2. Позначте кілька збережених записів.
3. Натисніть **Export selected ZIP / Експорт вибраних ZIP**.

ZIP містить:

- Markdown-файл для кожного вибраного чату;
- структуру папок;
- `library.json` із метаданими;
- `README.txt`.

Ліміти однієї масової операції:

- до 100 чатів;
- до 12 MB збереженого Markdown-контенту.

---

## 9. Резервна копія та відновлення

### Створити backup

1. Відкрийте локальну бібліотеку чатів.
2. У секції Backup натисніть **Створити копію**.
3. Збережіть JSON-файл у надійному місці.

Backup включає:

- збережені локальні чати;
- папки;
- теги;
- нотатки;
- локальну бібліотеку промптів.

### Відновити backup

1. Натисніть **Відновити**.
2. Виберіть раніше створений JSON backup.
3. Підтвердьте заміну локальних даних.

Відновлення замінює поточну локальну бібліотеку даними з backup-файлу.

---

## 10. Передати виділений текст із сайту

1. Відкрийте будь-яку вебсторінку.
2. Виділіть потрібний текст.
3. Натисніть іконку ChatExtra Toolkit.
4. Натисніть **Виділений текст**.
5. За першого використання Chrome може попросити дозвіл на `chatgpt.com`.
6. Відкриється новий ChatGPT-чат із вставленим текстом.
7. Перевірте текст і надішліть його вручну.

Максимальний розмір виділення обмежений для стабільної роботи браузера.

---

## 11. Передати поточну вебсторінку

1. На потрібному сайті натисніть іконку ChatExtra Toolkit.
2. Натисніть **Поточна сторінка**.
3. Розширення локально підготує:
   - заголовок;
   - URL;
   - очищений основний текст.
4. Меню, форми, реклама, сайдбари, скрипти та інший типовий шум відсіюються.
5. Підготовлений текст вставляється у новий ChatGPT-чат без автоматичного надсилання.

Якщо сторінка дуже довга, текст скорочується й додається відповідна примітка.

---

## 12. Передати видимий скриншот

1. Відкрийте потрібну сторінку й прокрутіть до потрібного місця.
2. Натисніть ChatExtra Toolkit.
3. Натисніть **Видимий скриншот**.
4. Розширення робить JPEG тільки видимої області поточної вкладки.
5. У новому ChatGPT-чаті з'являється лише зображення, без автоматично доданого тексту сторінки.
6. Надсилання виконуєте вручну.

---

## 13. Передати субтитри / транскрипт YouTube

1. Відкрийте YouTube-відео.
2. Якщо доступний «Текст відео / Transcript», бажано відкрити його.
3. Натисніть іконку ChatExtra Toolkit.
4. Для YouTube з'явиться додаткова кнопка **Субтитри YouTube**.
5. Натисніть її.
6. Розширення читає доступний транскрипт, відкидає службові заголовки та поле пошуку й вставляє текст у новий ChatGPT-чат.

Якщо YouTube не надає доступного транскрипту для конкретного відео, функція повідомить про це.

---

## 14. Дозволи Chrome

ChatExtra Toolkit використовує мінімальний набір обов'язкових дозволів:

- `activeTab` — працювати лише з вкладкою, на якій користувач сам викликав розширення;
- `scripting` — читати потрібний контент сторінки або ChatGPT після явної дії користувача;
- `downloads` — зберігати локальні файли експорту.

Опціонально запитується доступ лише до `https://chatgpt.com/*` для вставлення підготовленого контенту у новий ChatGPT-чат.

Широких постійних host permissions немає.

## 15. Типові проблеми

### Відкрилося меню сайту замість меню ChatGPT

У версії 2.0.0 маршрутизація перевіряє активну вкладку при кожному кліку. Якщо після оновлення розширення ще показується старе меню, відкрийте `chrome://extensions` і один раз натисніть Reload на ChatExtra Toolkit.

### Розширення не бачить повідомлення

Оновіть саму сторінку ChatGPT і дочекайтеся повного завантаження розмови.

### Не знайшло вкладення для ZIP

Деякі тимчасові файли ChatGPT мають короткоживучі URL. Відкрийте/активуйте файл у ChatGPT або Library й повторіть експорт.

### YouTube не віддає субтитри

Відкрийте панель «Текст відео / Transcript» і повторіть дію. Якщо транскрипт відсутній у самому YouTube, розширення не може створити його самостійно.

### Backup не відновлюється

Перевірте, що вибрано JSON-файл, створений функцією Backup цієї версії розширення.

## 16. Chrome Web Store та оновлення

Версію 2.0.0 слід завантажувати як оновлення існуючого Chrome Web Store item з ID:

`ingagbhapppiiiccljbhiledobnmhhfb`

Це збереже поточних користувачів, відгуки та історію продукту. Окремий новий item потрібен лише тоді, коли свідомо створюється інший продукт із власною аудиторією та новим extension ID.

Назва продукту у 2.0.0: **ChatExtra Toolkit**.

У публічному описі можна пояснювати, що це набір інструментів для ChatGPT, але розширення має залишатися чітко позначеним як незалежне й неофіційне.

## 17. Короткий щоденний сценарій

**Для експорту чату:** ChatGPT → іконка → вибрати повідомлення → формат → Export.

**Для промпту:** ChatGPT → іконка → нижче основного експорту → бібліотека промптів → Copy.

**Для архіву:** ChatGPT → іконка → локальна бібліотека чатів → папка/теги/нотатка → Save current chat.

**Для сайту:** сайт → іконка → Виділений текст / Поточна сторінка / Скриншот.

**Для YouTube:** відео → за потреби відкрити Transcript → іконка → Субтитри YouTube.

**Для резервної копії:** ChatGPT → іконка → локальна бібліотека чатів → Backup → Створити копію.
